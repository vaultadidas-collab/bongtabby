# Bông Tabyy

Trang giới thiệu pate và hạt cho mèo, gắn link Shopee. Không phải cửa hàng chính hãng Mr.Vet.

## Đưa lên GitHub Pages

1. Tạo repo public tên `bongtabyy`.
2. Kéo cả thư mục này vào repo, `index.html` nằm ngay gốc.
3. Settings, Pages, nhánh `main`, thư mục gốc.
4. Khi có tên miền, tìm `bongtabyy.vn` trong các file html và `sitemap.xml`, đổi thành tên miền đó.

Ảnh sticker để đăng kèm. Ảnh bìa món trên Shopee dùng bản không sticker.
